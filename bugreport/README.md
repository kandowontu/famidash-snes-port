# Calypsi 65816 reproducers

Three defects found in Calypsi 5.18 while porting Famidash to the SNES. All
three are worth reporting upstream to
[hth313/Calypsi-tool-chains](https://github.com/hth313/Calypsi-tool-chains).

Common build flags: `--code-model large --data-model large -O 1`.

## 1. Value lost at a control-flow merge — the expensive one

`repro_calypsi.c` + `gamemodes/gamemode_cube.h`, built by:

```bash
sh bugreport/make_repro.sh
```

A value computed on every incoming edge of a merge is discarded at the join,
which instead reads a stack slot that nothing in the function ever writes. The
slot holds whatever the caller left on the stack, so the result is stable across
frames and looks like plausible-but-wrong data rather than a crash.

The script prints three instances:

| Function | Source | Emitted |
|---|---|---|
| `common_gravity_routine` | `register int16_t` live across `switch (gravity_mod)` | cases read it with `tya`; the join does `lda 1,s` |
| `cube_eject` | `vel_y = grav ? 0xffff : 0` | `lda 1,s` at the join discards both arms |
| `cube_movement` | `tmp3 = (charge > 45 ? 45 : charge)` | one arm stores `1,s`, the other leaves A; join reads `3,s` |

`common_gravity_routine` also emitted a spurious `tya` at a second join, in a
branch that did not involve the register variable at all.

**Reduction did not work, and the reduced cases are not the bug.** A standalone
`out = flag ? hi : 0;` compiles correctly, with or without a stack frame in the
enclosing function, at every optimisation level. The defect only appears in the
full translation unit, so the reproducer is that unit: `repro_calypsi.i` is the
preprocessed source (~2800 lines), regenerated by the script above. See
`docs/HANDOFF.md` trap 3 (delta debugging) for why a reduced repro was not shipped instead.

`tools/scan_stackslots.py` detects the pattern in generated assembly and runs as
part of `tools/build_game.sh`. It is the practical defence: the miscompilation
is silent at build time, and the runtime symptom (Famidash's player accelerating
downward by a constant `-0x3900` per frame instead of by gravity, and so never
landing) points nowhere near the compiler.

Workaround: write the merge out long-hand so that every branch performs its own
store and no value has to survive the join.

## 2. Computed goto ICEs the backend

`&&label` / `goto *expr` crashes the 65816 backend. `SAUCE/functions/collision.h`
uses it; `overlay/functions/collision.h` rewrites it as a switch.

```c
int c; int f(void){ void *p = &&a; goto *p; a: return 1; }
```

## 3. Empty block-scope array initializer ICEs

Separate from 2:

```c
void f(void){ int jt[] = {}; }
```
